# Estrutura_de_Dados_II
# 📚 Estrutura de Dados II

Repositório dedicado aos estudos e atividades da disciplina **Estrutura de Dados II**.

Durante esta disciplina, estou aprofundando meus conhecimentos sobre diferentes estruturas e técnicas fundamentais para a programação e resolução de problemas.

## 📖 Conteúdos estudados

* 🌳 **Árvores**

  * Estrutura e organização de árvores
  * Árvores binárias
  * Percursos em árvores

* 🔢 **Matrizes**

  * Matrizes bidimensionais
  * Manipulação e acesso aos elementos
  * Aplicações em algoritmos

* 📚 **Pilhas**

  * Conceito **LIFO** (*Last In, First Out*)
  * Operações de inserção e remoção
  * Aplicações práticas

* 🚶 **Filas**

  * Conceito **FIFO** (*First In, First Out*)
  * Operações de entrada e saída
  * Aplicações em algoritmos

* 🔄 **Recursividade**

  * Conceito de funções recursivas
  * Casos base e casos recursivos
  * Aplicações em estruturas de dados e algoritmos

## 🎯 Objetivo

Este repositório tem como objetivo registrar minha evolução durante a disciplina, reunindo **exercícios, implementações, anotações e projetos** relacionados aos conteúdos estudados.

> 💡 **Em constante aprendizado:** este repositório será atualizado conforme novos conteúdos forem abordados durante as aulas.
