
# 🌳 Jogo Educativo - Árvores AVL

## 📚 Sobre o projeto

Este projeto foi desenvolvido para a disciplina de Estrutura de Dados II com o objetivo de ensinar, de forma interativa, o funcionamento das **Árvores AVL**.

O jogo apresenta o conceito de uma árvore de busca e mostra como ela pode ficar **desbalanceada** quando novos valores são inseridos.

Quando a árvore fica desequilibrada, são utilizadas **rotações para a direita ou para a esquerda** para reorganizar os nós e manter a árvore balanceada.

## 🎮 Como funciona

O jogador insere valores na árvore e acompanha sua organização.

Durante o jogo, é possível observar:

- 🌱 Inserção de novos nós;
- ⚖️ Fator de balanceamento;
- 🔄 Rotações para a direita;
- 🔄 Rotações para a esquerda;
- 🌳 Organização da árvore;
- 📊 Manutenção do equilíbrio da árvore AVL.

A ideia é transformar um conceito de Estrutura de Dados em uma experiência mais visual e interativa.

## 🧠 O que é uma Árvore AVL?

Uma Árvore AVL é uma árvore de busca binária que realiza ajustes automaticamente para evitar que um dos lados fique muito maior que o outro.

Quando ocorre um desequilíbrio, a árvore utiliza rotações para reorganizar seus nós.

### Exemplo

Uma árvore pode ficar assim:

text
        50
       /
      40

    30
